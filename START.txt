BASA · Сайт и публикация

ПОСМОТРЕТЬ
1. Распакуйте весь ZIP в обычную папку на компьютере.
2. Откройте папку site и дважды нажмите index.html. Откроется сайт. Ничего устанавливать для просмотра не требуется.
3. В screenshots есть снимки первых экранов и страниц целиком. Проверки описаны в QA.txt.

ОПУБЛИКОВАТЬ НА GITHUB PAGES
1. В своём GitHub создайте новый публичный репозиторий. Для бесплатного GitHub Pages на плане Free нужен публичный репозиторий.
2. Откройте репозиторий. Через Add file → Upload files перенесите СОДЕРЖИМОЕ папки site. На верхнем уровне должны лежать index.html, assets и portfolio. Если .nojekyll скрыт, его можно добавить через Add file → Create new file с именем .nojekyll и пустой строкой внутри. Папки tools и screenshots предназначены для вас.
3. Нажмите Commit changes. Откройте Settings → Pages. В Build and deployment выберите Deploy from a branch, ветку main и папку /(root). Нажмите Save.
4. Когда GitHub завершит публикацию, в Settings → Pages появится Visit site. Проверьте его на телефоне, откройте обложку и нажмите «Обсудить проект».
5. Для карточки ссылки в соцсетях откройте site/index.html в текстовом редакторе. Найдите assets/art/share.jpg в строке og:image и укажите полный HTTPS-адрес этой картинки на вашем опубликованном сайте. Например, к адресу сайта с завершающим / добавьте assets/art/share.jpg. Обновите index.html в репозитории. Пока адрес сайта неизвестен, указан относительный путь.

ИЗМЕНИТЬ ТЕКСТ И КОНТАКТЫ
• Откройте site/index.html в текстовом редакторе в кодировке UTF-8. Через Ctrl+F найдите видимую фразу. Меняйте слова между угловыми скобками, сохраняйте разметку. Нажмите Ctrl+S, затем обновите страницу.
• Чтобы изменить личный Telegram, замените все вхождения https://t.me/basa69 и подпись @basa69. Канал меняется отдельно заменой https://t.me/basaprod. Ссылки открываются в одно нажатие.
• Цвета вынесены в начало site/assets/site.css, строка :root. Шрифты и их лицензии находятся в site/assets/fonts.

ИЗМЕНИТЬ BEHANCE И ВИДЕО
• Откройте site/index.html. Поиск «Портфолио на Behance» приведёт к адресу кнопки.
• Найдите «ВИДЕО RUTUBE». Каждый блок от <li> до </li> содержит адрес видео (href), обложку (src), длительность и название (h3). Для добавления ролика скопируйте такой блок. Для перестановки переместите его целиком. Сохраните файл и обновите страницу.
• Обложки находятся в site/assets/videos. Оформление новых элементов — в site/assets/video-gallery.css.

ОБНОВИТЬ ПОРТФОЛИО
1. Откройте site/portfolio/cases.json. У каждой работы есть short_title (подпись на странице), title (заголовок источника), views_approx (округлённые просмотры числом), views_display (их текстовое представление), category, thumbnail (обложка) и source (оригинальный скриншот).
2. Для новой работы положите обложку в portfolio/thumbnails, скриншот — в portfolio/original_screenshots. Скопируйте целиком одну запись в JSON, отделите запятой, задайте новый уникальный id латиницей и имена обоих файлов. Для video_url используйте проверенную ссылку или null. У существующей работы меняйте просмотры вместе с подтверждающим скриншотом.
3. После сохранения на Windows дважды нажмите tools/Обновить-портфолио.cmd. Для этой операции нужен Python 3.9+ с python.org. На macOS/Linux из папки с START.txt выполните python3 tools/update_portfolio.py. Библиотеки устанавливать не нужно.
4. Откройте site/index.html и проверьте изменения. Карточки и подписи с просмотрами над обложками обновляются вместе. Общие показатели «Более 2 млн» и «×2,5» заданы отдельно в index.html. Три лидера по просмотрам занимают первый ряд. В hero приоритет у talgo, dodo и tank500.
5. Чтобы обновить опубликованную страницу, загрузите обновлённое содержимое site в тот же репозиторий. Редактировать текст и использовать сайт можно без Python. Скрипт нужен только после изменения данных портфолио.

Формат поставки — один статический сайт. Файлы в site одновременно являются исходниками и готовой версией для загрузки на хостинг. Все шрифты и изображения локальные.
